## Status
ROADMAP-MERGED. RiemannianGeometry R5a.2 (minimality H = 0, first variation) and R5b (second variation Q, Jacobi operator, stability, Dirichlet index on relatively compact domains) specify it for immersions into Riemannian manifolds; not implemented. Depends on #49.

## Mathlib
Nothing on minimal submanifolds. Prerequisites: immersions, Riemannian metrics, Levi-Civita, Riemannian measure is not in Mathlib in general.

## Tau Ceti code
No minimal hypersurface, area variation, Jacobi operator or Morse index. Relevant pieces: Euclidean `TauCeti.secondFundamentalForm`; coercive-form spectral theory `IsCoercive.formSolutionOperator`, `IsCoercive.exists_hilbertBasis_forall_apply_eq_smul_inner`, `IsCoercive.isLeast_rayleighQuotient` (named in R5b as suppliers); Riemannian volume/divergence pieces from DifferentialGeometry.

## Merged roadmaps
- RiemannianGeometry R5a.2: H, minimality = H = 0, first variation formula `δVol = ∫div X^⊤ − m⟨H,X^⊥⟩`, stationarity iff H = 0, minimal cones. Not implemented.
- RiemannianGeometry R5a.1: orientation-free C² relative-volume functional for compactly supported variations. Not implemented.
- RiemannianGeometry R5b: second variation Q(V,W), normal Jacobi operator, stability, two-sided scalar form L = Δ⁺ − (|A|² + Ric(ν,ν)), Dirichlet Jacobi operator L_D and "index of Q on V = number of negative eigenvalues of L_D" on relatively compact smooth domains, full-scalar stability inequality. Not implemented (STATUS: R5b not begun).
- GeometricCurrents G6/G7: smooth minimal hypersurfaces as regularity output (2 ≤ n ≤ 7).
- Gaps vs def #52: Morse index/nullity of a closed (compact boundaryless) minimal hypersurface is the D = P case, implicit but not stated; bumpy metrics, "geometrically distinct" not targets.

## Prerequisite chain
Riemannian manifold, Levi-Civita [Mathlib] -> B, S, H (#49) [R5a/R5a.2, not implemented] -> relative volume [R5a.1, not implemented; needs DifferentialGeometry Layer 12 densities] -> first variation [R5a.2, not implemented; needs R5a.1 and DifferentialGeometry Layer 12 integration/divergence] -> minimal immersion H = 0 [R5a.2] -> second variation, Jacobi operator, stability [R5b] -> Dirichlet index/nullity [R5b, on compact domains; closed case implicit] -> bumpy metrics [unplanned].

## Library-scale gap
Essentially covered; the residue (index/nullity on closed hypersurfaces stated globally, bumpy metrics with White's theorem, one-sided hypersurfaces' index via double cover) is a modest extension of R5b. A min-max roadmap (Almgren-Pitts, Marques-Neves; Colding-Minicozzi, *A Course in Minimal Surfaces*) would be the natural consumer for the Annals papers (Song, Zhou, Chodosh-Mantoulidis).
