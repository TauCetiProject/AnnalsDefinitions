Definition 94.2 is in Tau Ceti for classes of a relational language: `TauCeti.RelationalConfiguration.BorelComplete K` for `K : Set (RelationalConfiguration L ℕ)` (the isomorphism relation `classIso K'` of every invariant Borel class of every countable relational language Borel reduces to `classIso K`, over Tau Ceti's `Setoid.BorelReducible`, Def 94.1), with transfer, bireducibility, universe and renaming API and the reformulations (3) and (4) of 94.4 (`TauCeti/ModelTheory/RelationalConfiguration/BorelComplete.lean`, CountableStructureSpacesPartII §1.2). The merged roadmap [CountableStructureSpacesPartII](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/CountableStructureSpacesPartII/README.md) §1.3 reads Borel completeness of a functional class through its image under the graph-code map; the functional coding space and the graph-code homeomorphism are in code (`TauCeti.FunctionalConfiguration`, `graphCodeHomeomorph`), so the paper's statement can be written as `BorelComplete` of the image of the class, but the transfer of invariant Borel classes along the graph code that makes this the right notion is not (open Tau Ceti PR https://git.taucetiproject.org/TauCetiProject/TauCeti/pulls/4331). Borderline: the relational case is all of 94.2 except function-symbol languages, and those reach it through code that exists. The roadmap also specifies the Friedman–Stanley theorem (Layers 2–3: graphs, trees and linear orders are Borel complete, 94.3), the Becker–Kechris universal embedding (Layer 4), the equivalent characterisations (Layer 5, 94.4) and consequences (Layer 6: not Borel, above E₀, continuum many classes, unbounded Scott height, the Friedman–Stanley obstruction).
