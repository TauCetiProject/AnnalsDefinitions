# 27. Perfect obstruction theory and virtual fundamental class

## Status
ROADMAP-PR. Open PR #1996 (VirtualFundamentalClass) specifies exactly Behrend–Fantechi: intrinsic normal cone, obstruction theories, `[X,φ]^vir ∈ A_n(X)_ℚ` with global resolution, and the relative version; open PR #1998 (GromovWittenTheory) Layer 4 specifies the Gromov–Witten obstruction theory and class (27.7). Nothing implemented.

Depends on #16 (rational Chow groups of DM stacks) and #24 (for 27.7).

## Library-scale gap
Fully planned in PRs #1996 and #1998. The paper additionally uses torus-equivariant virtual localization (Graber–Pandharipande) and Kiem–Li cosection localization, which PR #1996's boundary explicitly excludes; these would be a follow-on roadmap beside VirtualFundamentalClass. References: Behrend–Fantechi, *The intrinsic normal cone*; Behrend, *Gromov–Witten invariants in algebraic geometry*; Fulton, *Intersection theory*.
