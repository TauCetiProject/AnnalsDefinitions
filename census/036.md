1. C*-algebras, positive functionals, CP maps, `CStarMatrix`, `Matrix.trace`: in Mathlib.
2. Tracial state (as a structure): implicit in Tau Ceti (`isKMSState_zero_iff`); `IsTracialState`, `T(A)`: PR #2260 §1.1.
3. Normalised trace and 2-norm on `M_n`: PR #2260 §1.5 (on Tau Ceti's Frobenius inner product).
4. c.p.c. maps into `M_n`: Mathlib `CompletelyPositiveMap` plus contractivity; CStarAlgebras C4.1 (merged, not implemented) for the API; PR #2260 Layer 2.
5. Amenable trace (Def 36.3): PR #2260 §3.1.
6. Equivalences (Prop 36.4): sequences and u.c.p. maps PR #2260 §3.2; hypertraces PR #2260 §§4.1–4.4 (needs CStarAlgebras C2.1, unital case in code, and C5.1–C5.2); nuclear and exact cases PR #2260 §§5.3–5.4 (need CStarAlgebras C6, C7.1 and VonNeumannAlgebras V13a–V13b, merged, not implemented); pullback PR #2260 §3.4.

## Library-scale gap
PR #2260 is the roadmap for this layer (Brown, *Invariant means and finite representation theory of C*-algebras*, Mem. AMS 2006; Brown–Ozawa, *C*-Algebras and Finite-Dimensional Approximations*, Ch. 6; Schafhauser 2020): what remains is its review and merging. Implementation then waits on the CStarAlgebras layers it consumes (C4 completely positive maps, C5 tensor products, C6 nuclearity, C7 exactness, C8 quasidiagonality), of which only C2.1 (unital) and the bounded-product part of C5.4 are in code, and on VonNeumannAlgebras Layer 13.
