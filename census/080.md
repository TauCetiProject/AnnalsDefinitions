# 80. The Néron–Tate (canonical) height on an abelian variety

## Status
ROADMAP-MERGED. Merged [HeightsRationalPointsAndObstructions](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/HeightsRationalPointsAndObstructions/README.md) (PR #1017) specifies Tate's limit (Prop. 80.1) as §0.18 `tateLimit` and the Néron–Tate height `ĥ_L` (Def. 80.2) as §0.19 `neronTateHeight`, for abelian `A/K` over generalized global fields (§0.9), which include number fields and one-variable function fields (§0.10, including constant fields not algebraically closed in `K`), with exactly the symmetric/antisymmetric/general clauses; Prop. 80.3 is §§0.19–0.21 and §1.11 (Lang–Néron kernel). Its number-field Weil height class and Northcott come from merged ArakelovGeometryAndAbelianHeights §§1.12–1.14. The Jacobian normalisation `ĥ = ½ĥ_Θ` is recorded in merged ArakelovGeometryAndAbelianHeightsPartII (PR #1833) Conventions and §8.4 (`h_Θ̄ = 2ĥ`, `ĥ` half of `ĥ_Θ`), on the twice-theta bundle `Θ_X` of merged JacobianChallengePartII §§3.2–3.13. Tau Ceti has only the elliptic-curve case over a field with admissible absolute values.

## Mathlib
- Has: absolute Weil heights `Height.mulHeight`, `Height.logHeight`, `logHeight₁`, `Projectivization.logHeight`, the class `Height.AdmissibleAbsValues` with an instance only for number fields (`NumberTheory/Height/NumberField.lean`), Northcott (`NumberTheory/Height/Northcott.lean`), the naive height on Weierstrass curves `WeierstrassCurve.Affine.Point.naiveHeight` and the approximate parallelogram law (`NumberTheory/Height/EllipticCurve.lean`).
- Missing: abelian varieties, the Weil height machine for line bundles, Tate's limit lemma in general, `ĥ_L`, function-field heights.
