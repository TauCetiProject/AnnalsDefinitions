# 80. The Néron–Tate (canonical) height on an abelian variety

## Status
ROADMAP-PR. Tau Ceti has only the elliptic-curve case over a field with admissible absolute values. The general Néron–Tate height `ĥ_L` on an abelian variety over a number field or a one-variable function field is §0.19 of open PR #1017 "Heights, rational points and obstructions". That PR includes the symmetric/antisymmetric split, Tate's limit, positivity and the kernel, and takes the number-field Weil height class and Northcott from merged ArakelovGeometryAndAbelianHeights §§1.12–1.14 (not implemented). No merged roadmap specifies `ĥ_L`.

## Mathlib
- Has: absolute Weil heights `Height.mulHeight`, `Height.logHeight`, `logHeight₁`, `Projectivization.logHeight`, the class `Height.AdmissibleAbsValues` with an instance only for number fields (`NumberTheory/Height/NumberField.lean`), Northcott (`NumberTheory/Height/Northcott.lean`), the naive height on Weierstrass curves `WeierstrassCurve.Affine.Point.naiveHeight` and the approximate parallelogram law (`NumberTheory/Height/EllipticCurve.lean`).
- Missing: abelian varieties, the Weil height machine for line bundles, Tate's limit lemma in general, `ĥ_L`, function-field heights.

## Tau Ceti code
- Elliptic case: `WeierstrassCurve.Affine.Point.canonicalHeight` (`AlgebraicGeometry/EllipticCurve/CanonicalHeight/Basic.lean`), `lim h(x(2ⁿP))/4ⁿ`, which is `ĥ_{O(2[O])}`. Also `canonicalHeightQuadratic`, `neronTatePairing` (half the polarisation), `canonicalHeight_eq_zero_iff_isOfFinAddOrder`, `abs_canonicalHeight_sub_naiveHeight_le`, isogeny compatibility `neronTatePairing_pointMap` (`CanonicalHeight/Isogeny.lean`).
- Abelian varieties: `TauCeti.AlgebraicGeometry.AbelianVariety` with products, morphism groups, tangent space, isogenies (`AlgebraicGeometry/AbelianVariety/`). No line bundles on them, no `[-1]^*`, theorem of the cube, `Pic⁰`/NS, and no Jacobian variety (only the functor `relativePicardDegreeZeroFunctor` and Abel–Jacobi on functors of points).
- Missing: the definition for any abelian variety of dimension > 1, the Weil height machine and the theta divisor on a Jacobian.

## Open roadmap PRs
- #1017 "Heights, rational points and obstructions": §0.18 `tateLimit` (= Prop. 80.1), §0.19 `neronTateHeight` for abelian `A/K` over generalized global fields with exactly the symmetric/antisymmetric/general clauses of Def. 80.2 (and the normalisation check `O_E(O) ↦ canonicalHeight/2`), §0.20 positivity and the number-field torsion kernel, §0.21 `neronTateForm`, §1.11 function-field height kernel (Lang–Néron) (`neronTateHeight_eq_zero_iff_trace`). Earlier layers build the Weil machine over generalized global fields; §0.10 "Polarized function fields" assumes the constant field `k` algebraically closed in `K`. #1017 builds on merged ArakelovGeometryAndAbelianHeights §§1.12–1.14, whose height class it calls `Height.weilClass` (supplier contract, README l.86 of the PR): §0.16 "Weil's height machine" is, over a number field `K`, `[K:ℚ]` times that class, and §0.20 "Positivity and the height kernel" takes Northcott from the same §1.13. The Jacobian normalisation `ĥ = ½ĥ_Θ` is not a #1017 target: §5.10 "Vojta's inequality for curves" uses `L = O(Θ + [−1]^*Θ)` with `b_L/2 = b_Θ` only inside that proof.
- #1821 "HeightsRationalPointsAndObstructionsPartII" (Néron–Tate distance and uniform Bogomolov, §§4.3, 5.1) and #1833 "ArakelovGeometryAndAbelianHeightsPartII" (Layer 6 Néron–Tate kernel, adelic `Θ̄`) consume it.

## Prerequisite chain
1. Absolute heights on `ℙⁿ(K̄)` over number fields: Mathlib. Over one-variable function fields: unplanned in code, target in PR #1017 §0.9 "Generalized global fields".
2. Weil height machine `L ↦ h_L` modulo bounded functions: target in PR #1017 §§0.1–0.17, whose number-field case is `[K:ℚ]` times the Weil height class of merged ArakelovGeometryAndAbelianHeights §1.13 (not implemented).
3. Abelian varieties: Tau Ceti (basic). Line bundles on them with the theorem of the cube: target JacobianChallenge §E.1 (merged, not implemented); the `[n]^*` formula for symmetric/antisymmetric bundles: target AbelianSchemesAndArithmeticModuli §A1.5 (merged, not implemented).
4. Tate's limit lemma: target PR #1017 §0.18.
5. `ĥ_L` and its properties: target PR #1017 §§0.19–0.21 (§0.20's Northcott from merged ArakelovGeometryAndAbelianHeights §1.13). Elliptic special case in Tau Ceti.
6. Jacobian `J = Pic⁰` and symmetric theta divisor `Θ`, `ĥ = ½ĥ_Θ`: the Jacobian is a target in JacobianChallenge §D.8 (merged, partial; representability blocked on SchemeAndStackFoundations §4.14). The theta divisor `θ_{x₀}` is JacobianChallenge §E.5 (merged); the symmetric twice-theta bundle `Θ_X` is merged JacobianChallengePartII §§3.2–3.13 (not started). The height `½ĥ_Θ` itself is unplanned as a named target.

## Library-scale gap
Small. Two pieces are unplanned: the Jacobian normalisation `ĥ = ½ĥ_Θ` (PR #1017 §0.19 applied to the `Θ_X` of JacobianChallengePartII §§3.2–3.13, not a target of either), and function fields whose constant field is not algebraically closed in `K` (PR #1017 §0.10 assumes it is; reducing to the algebraic closure of `k` in `K` is a short addition there). Caveat on normalisation, matching the writer's note: Tau Ceti `canonicalHeight` equals `ĥ_{O(2[O])} = 2ĥ_{O([O])}`, and #1017 §0.19's Checks already record this.
