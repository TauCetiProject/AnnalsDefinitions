# 80. The Néron–Tate (canonical) height on an abelian variety

## Status
ROADMAP-PR. Tau Ceti has only the elliptic-curve case over a field with admissible absolute values. The general Néron–Tate height `ĥ_L` on an abelian variety over a number field or a one-variable function field is §0.19 of open PR #1017 "Heights, rational points and obstructions". That PR includes the symmetric/antisymmetric split, Tate's limit, positivity and the kernel. No merged roadmap specifies it.

## Mathlib
- Has: absolute Weil heights `Height.mulHeight`, `Height.logHeight`, `logHeight₁`, `Projectivization.logHeight`, the class `Height.AdmissibleAbsValues` with an instance only for number fields (`NumberTheory/Height/NumberField.lean`), Northcott (`NumberTheory/Height/Northcott.lean`), the naive height on Weierstrass curves `WeierstrassCurve.Affine.Point.naiveHeight` and the approximate parallelogram law (`NumberTheory/Height/EllipticCurve.lean`).
- Missing: abelian varieties, the Weil height machine for line bundles, Tate's limit lemma in general, `ĥ_L`, function-field heights.

## Tau Ceti code
- Elliptic case: `WeierstrassCurve.Affine.Point.canonicalHeight` (`AlgebraicGeometry/EllipticCurve/CanonicalHeight/Basic.lean`), `lim h(x(2ⁿP))/4ⁿ`, which is `ĥ_{O(2[O])}`. Also `canonicalHeightQuadratic`, `neronTatePairing` (half the polarisation), `canonicalHeight_eq_zero_iff_isOfFinAddOrder`, `abs_canonicalHeight_sub_naiveHeight_le`, isogeny compatibility `neronTatePairing_pointMap` (`CanonicalHeight/Isogeny.lean`).
- Abelian varieties: `TauCeti.AlgebraicGeometry.AbelianVariety` with products, morphism groups, tangent space, isogenies (`AlgebraicGeometry/AbelianVariety/`). No line bundles on them, no `[-1]^*`, theorem of the cube, `Pic⁰`/NS, and no Jacobian variety (only the functor `relativePicardDegreeZeroFunctor` and Abel–Jacobi on functors of points).
- Missing: the definition for any abelian variety of dimension > 1, the Weil height machine and the theta divisor on a Jacobian.

## Prerequisite chain
1. Absolute heights on `ℙⁿ(K̄)` over number fields: Mathlib. Over one-variable function fields: unplanned in code, target in PR #1017 §0.9 "Generalized global fields".
2. Weil height machine `L ↦ h_L` modulo bounded functions: target in PR #1017 §§0.1–0.17 (also ArakelovGeometryAndAbelianHeights in PR #1000 §1.13 for metrised heights).
3. Abelian varieties: Tau Ceti (basic). Line bundles on them with symmetric/antisymmetric decomposition and the theorem of the cube: target JacobianChallenge Layer E (merged, not implemented).
4. Tate's limit lemma: target PR #1017 §0.18.
5. `ĥ_L` and its properties: target PR #1017 §§0.19–0.21. Elliptic special case in Tau Ceti.
6. Jacobian `J = Pic⁰` and symmetric theta divisor `Θ`, `ĥ = ½ĥ_Θ`: Jacobian is a target in JacobianChallenge Layer D (merged, partial; representability blocked on SchemeAndStackFoundations §4.14). The theta divisor `θ_{x₀}` as the image of `C^{g-1}` is in JacobianChallenge Layer E / PR #1225.

## Library-scale gap
None beyond the roadmapped work. Caveat on normalisation, matching the writer's note: Tau Ceti `canonicalHeight` equals `ĥ_{O(2[O])} = 2ĥ_{O([O])}`, and #1017 §0.19's Checks already record this.
