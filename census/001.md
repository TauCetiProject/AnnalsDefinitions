# 1. Real rank of a semisimple Lie group

## Status
PREREQS-ROADMAPPED. Real rank (dim of a maximal abelian 𝔞 ⊆ 𝔭) is not a target anywhere, but its inputs (Cartan involution of a real semisimple Lie algebra, Cartan decomposition, maximal abelian 𝔞 ⊆ 𝔭 with restricted roots, `Ad(K)𝔞 = 𝔭`) are merged targets in RepresentationTheory/LieGroups Layers 7 and 9, not yet implemented beyond `GL n`.

## Mathlib
- Has: `LieAlgebra.IsSemisimple`, `LieAlgebra.IsSimple` (`Algebra/Lie/Semisimple/Defs.lean`) with decomposition into simple ideals; `killingForm` (`Algebra/Lie/TraceForm.lean`), `LieAlgebra.IsKilling`, `rootSystem` of a split Cartan (`Algebra/Lie/Weights/RootSystem.lean`); `LieGroup` (`Geometry/Manifold/Algebra/LieGroup.lean`) and `LeftInvariantDerivation`.
- Missing: real forms, Cartan involutions, Cartan decomposition, compact Lie algebras, restricted roots, real rank. No maximal ℝ-split tori.

## Tau Ceti code
- Only special cases: `LieAlgebra.Symplectic.cartanInvolution` with `killingForm_cartanInvolution_self_neg` for `sp` (`Algebra/Lie/Symplectic/{Cartan,Killing}.lean`); smooth Iwasawa/Cartan decomposition for `GL n` only (`TauCeti.iwasawaDiffeomorph`, `Geometry/Lie/Iwasawa.lean`).
- No `CartanInvolution`, `IwasawaData`, restricted roots or real rank (grep for `CartanInvolution|IwasawaData|restrictedRoot|realRank` empty).
- Compact Lie algebras (LieGroups Layer 5A): the Killing form is negative definite on the derived algebra of a compact Lie group, which splits off the centre (`TauCeti/Geometry/Lie/Adjoint/Compact.lean`, `Algebra/Lie/InvariantForm/Positive.lean`).

## Merged roadmaps
- RepresentationTheory/LieGroups Layer 7 "Compact real forms of semisimple Lie algebras": defines the Cartan involution θ of a real semisimple 𝔤₀ and the positive form `−B(X,θY)`. STATUS: Layer 7 untouched.
- RepresentationTheory/LieGroups Layer 9 (Suggested.lean `CartanInvolution`, `IsRealReductive`, `IwasawaData` with "a maximal abelian 𝔞 ⊆ 𝔭", `restrictedRoots`, `restrictedRootSpace`, chamber; README "Restricted roots and KAK": "First prove Ad(K)a=p by the maximal-abelian symmetric-pair argument", restricted Weyl group `N_K(a)/Z_K(a)`). STATUS: Layer 9 partial, "the global real-reductive Cartan, Iwasawa and KAK decompositions beyond GL n" remaining.
- ReductiveGroups Layer 7 (absolute root datum with Galois action, relative root system for non-split groups) is the nearest Borel–Tits material, but it does not target maximal k-split tori or k-rank, and no merged roadmap does; ℝ-rank as `dim S` is not named. STATUS Layer 7 partial.
- RepresentationTheory/LieGroups Layer 5A: negative-definite Killing form on compact semisimple part (compact factors); done in code (`isCompl_center_derivedSeries_one_of_compactSpace`, `isSemisimple_derivedSeries_one_of_compactSpace`, `killingForm_derivedSeries_one_self_neg_of_compactSpace_of_ne_zero`), although STATUS still lists it as remaining.

## Open roadmap PRs
- #1037 AutomorphicFormsOnReductiveGroups §2.3a: consumes `IwasawaData`; mentions "In real rank one, `dim 𝔞=1`" only as a hypothesis for one lemma. Not a definition target.
- #871 ArithmeticLocallySymmetricSpaces ALS.0.1–0.3: Cartan involutions of real reductive groups, `IsCartanInvolution.conj` (conjugacy), maximal compacts.

## Prerequisite chain
1. Real semisimple Lie algebra, Killing form, simple ideals: Mathlib.
2. Cartan involution θ of 𝔤₀ (via compact real form): target LieGroups Layer 7 (merged, not implemented).
3. Cartan decomposition 𝔤 = 𝔨 ⊕ 𝔭: LieGroups Layer 9 (merged, partial; `GL n` only). Purely Lie-algebraic version needs only θ.
4. Maximal abelian 𝔞 ⊆ 𝔭 and conjugacy `Ad(K)𝔞 = 𝔭` (Theorem 1.2): LieGroups Layer 9 `IwasawaData` / "Restricted roots and KAK" (merged, not implemented); conjugacy of Cartan involutions: PR #871 ALS.0.1.
5. `rank_ℝ 𝔤 := finrank ℝ 𝔞`, well-definedness, additivity over simple ideals, `rank_ℝ = 0 ↔ compact`: unplanned (small).
6. Group version `rank_ℝ G := rank_ℝ (Lie G)`, "higher rank", almost-simple factors: unplanned.
7. Borel–Tits comparison with maximal ℝ-split torus: unplanned. Maximal k-split tori are not a target of ReductiveGroups Layer 7 or any other merged roadmap; the comparison would also need PR #1037 §2.3a's algebraic comparison.

## Library-scale gap
Small once LieGroups Layers 7 and 9 exist: a Lie-algebra-level section "restricted roots and real rank" (Knapp, *Lie Groups Beyond an Introduction*, Ch. VI §§2–5; Helgason Ch. V) defining θ-stable data purely algebraically, proving conjugacy of maximal abelian subspaces of 𝔭, the restricted root system (possibly non-reduced), and real rank with additivity and the compact-factor criterion. Natural home: an extension of LieGroups Layer 9 (or a Lie-algebra sub-layer before it, since none of this needs the group). Note that LieGroups Layer 9 carries 𝔞 as group-level data in `IwasawaData`; the papers mostly need the algebra-level invariant.
