# 11. Split classical groups Sp₂ₙ, SO_l and general spin groups GSpin_l

## Status
PARTIAL-CODE. Tau Ceti has `Sp₂ₘ` as a smooth reductive group scheme over any commutative ring, with a standard pinning, so Definition 11.1(1) is formalized. It also has the orthogonal group scheme of an arbitrary constant matrix (`TauCeti.ConstantForm`) and `SOₙ` for the identity form `XXᵀ = 1`, which is smooth, reductive and semisimple. That `SOₙ` is split only when `−1` is a square, so the split `SO_l` of 11.1(2) (form `J_l`) is a one-line instance that is not yet made. `GSpin_l` is missing: a Clifford model (connected reductive group scheme over a characteristic-0 field with a pinned root datum) is a target of merged [AutomorphicLFunctionsAndLocalFactorsPartII](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/AutomorphicLFunctionsAndLocalFactorsPartII/README.md) §0.0, which does not specify Definition 11.2's root datum, the spinor norm `ν` or the exact sequence `1 → G_m → GSpin → SO → 1`, and which needs MetaplecticAutomorphicForms §3.2a from open PR #1063; the root-datum definition (11.2) needs the existence theorem, which is a merged ReductiveGroups Layer 9D target (partial).

## Mathlib
- Has: `Matrix.symplecticGroup` (`LinearAlgebra/SymplecticGroup.lean`), `Matrix.specialOrthogonalGroup`, `Matrix.orthogonalGroup` (`LinearAlgebra/UnitaryGroup.lean`; groups of matrices, not schemes), `CliffordAlgebra` with `involute`, `reverse`, even subalgebra, `lipschitzGroup`, `pinGroup`, `spinGroup` (`LinearAlgebra/CliffordAlgebra/SpinGroup.lean`), `RootPairing`.
- Missing: affine group schemes, reductive groups, GSpin, dual groups.

## Tau Ceti code
- `Sp₂ₘ`: `TauCeti.Symplectic.definingHopfIdeal`, points `TauCeti.GLSymplecticFin`, smoothness, connectedness, reductivity, semisimplicity, centre, diagonal torus, root subgroups, `Symplectic.standardPinning` (`Algebra/AlgebraicGroup/Symplectic/*`).
- `SOₙ` (identity form): `Algebra/AlgebraicGroup/SpecialOrthogonal/*` (smooth, connected, `reductiveCommHopfAlgProperty_finiteTypeCoordinateHopfAlgebra`, semisimple, adjoint for odd `n`, centre, `SO₂` as a split torus when `√−1 ∈ R`). General constant forms: `TauCeti.ConstantForm` (`Algebra/AlgebraicGroup/ConstantForm/Basic.lean`), so `O(J_l)` exists; the `det = 1` cut and split torus/pinning for `J_l` do not.
- Clifford side (points over a field): `CliffordAlgebra.mem_lipschitzGroup_iff_involute_act_ι_mem_range_ι` (Lipschitz = Clifford group, `LinearAlgebra/CliffordAlgebra/Lipschitz/CliffordGroup.lean`), spinor norm and `Spin → SO` (`LinearAlgebra/CliffordAlgebra/Spin/SpinorNorm/*`), low-rank `Spin` comparisons (`Spin/LowRank/{Four,Five}.lean`). No GSpin group or scheme (grep `GSpin|generalSpin` empty).
- Root data, pinnings and their transport: `TauCeti.Pinning`, `Pinning.comapOfIso` (`Algebra/AlgebraicGroup/Pinning/*`); Chevalley data `Algebra/AlgebraicGroup/Chevalley/*`, including the braid and Coxeter relations of the Weyl representatives (`Chevalley/Braid/{Basic,DoubleBond,TripleBond,Coxeter}.lean`).

## Prerequisite chain
1. Matrix groups, Clifford algebras, Lipschitz/spin groups: Mathlib.
2. Affine group schemes over rings, `GLₙ`, Hopf-ideal subgroups, `ConstantForm`: Tau Ceti.
3. `Sp₂ₙ` as a split reductive group with pinning: Tau Ceti (done).
4. Split `SO_l` with form `J_l`: unplanned as a separate item; immediate from `ConstantForm J_l` plus the `SpecialLinear` cut, then torus/Borel/pinning (Tau Ceti has these only for the identity form).
5. Root data of `Sp`, `SO`, `GSpin`; existence theorem from a based root datum: ReductiveGroups Layers 7 and 9D (merged, partial).
6. `GSpin(V)` via Clifford even units normalizing `V`: AutomorphicLFunctionsAndLocalFactorsPartII §0.0 (merged, not implemented; needs open PR #1063). The exact sequence `1 → G_m → GSpin → SO → 1`, `ν` and `(G_m × Spin)/μ₂`: unplanned as targets (§0.0 uses the `μ₂` quotient only in a proof sketch).
7. Dual groups and `r_G` (Remark 1): ReductiveGroupsPartII RG2.5 (merged, untouched).

## Library-scale gap
Mostly planned. Missing as named items: the split orthogonal group of `J_l` as a pinned reductive group (a short addition beside Tau Ceti's `SpecialOrthogonal`), and a group-scheme GSpin over a general base (AutomorphicLFunctionsAndLocalFactorsPartII §0.0 restricts to characteristic 0 fields). Natural home: ReductiveGroups or ChevalleyGroups, as a "classical split groups" section with the low-rank identifications (`GSpin₃ ≅ GL₂`, `GSpin₅ ≅ GSp₄`). Reference: Knus–Merkurjev–Rost–Tignol, *The Book of Involutions*, §§12–13 and 23; Asgari, *Local L-functions for split spinor groups*.
