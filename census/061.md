## Status
ROADMAP-PR. Out(Γ) and the outer action Mod_{g,n} → Out(π₁(Σ_{g,n})), with the induced action on conjugacy classes of representations, are targets of PR #1231 §5.9 (and Out/Dehn-Nielsen-Baer for closed surfaces in PR #1169); PR #2266 §0.2 adds the based action of `PMod(g, b, p + 1)` on `π₁(Σ_{g,b,p}, x)`, the outer action of `PMod(g, b, p)`, and `pureMappingClassAut g n ≤ MulAut (surfaceGroup g n)` (automorphisms sending each peripheral loop to a conjugate), with the image of `PMod` contained in it. No merged roadmap specifies them for surfaces. Depends on #59.

## Mathlib
No `Out` as a named group, but `MulAut.conj : G →* MulAut G` (`Algebra/Group/End.lean`) makes `MulAut G ⧸ MulAut.conj.range` a one-liner. Basepoint change `FundamentalGroup.fundamentalGroupMulEquivOfPath`, induced maps `FundamentalGroup.mapOfEq` (`AlgebraicTopology/FundamentalGroupoid/FundamentalGroup.lean`).

## Tau Ceti code
- `TauCeti.ContinuousOut G = ContinuousAut G ⧸ conj.range` (`Topology/Algebra/Group/ContinuousAut/Basic.lean`); `outerAction : E ⧸ N →* ContinuousOut N` for group extensions (`.../ContinuousAut/OuterAction.lean`). With the discrete topology this is Out(Γ).
- Surface groups as presented groups `TauCeti.SurfaceGroup.Orientable g m` with peripheral elements (`GroupTheory/SurfaceGroup/Basic.lean`), not identified with the topological `π₁`.
- No homeomorphism-to-Out homomorphism for spaces, no mapping class groups.
