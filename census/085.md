# 85. Stable Faltings height of an abelian variety

## Status
ROADMAP-PR. Over number fields it is open PR #1000 "Arakelov geometry and heights of abelian varieties": §1.3 Arakelov degree (85.1–85.2), §2.1 Faltings metric with exactly the normalisation of 85.5, §3.1 `h(A/K)` and §3.4 stable `h_st(A)`. Over a one-variable function field, open PR #1833 "ArakelovGeometryAndAbelianHeightsPartII" §13.1 states the definition for curves of genus > 1 via their Jacobian, which is the case [2026, 203(1), no. 2] needs. Néron models and semistable reduction are PR #852. Nothing is merged or implemented.

## Mathlib
- Has: rings of integers, infinite places and embeddings `K →+* ℂ`, `Module.Finite`/projective modules, `Ideal.absNorm`, schemes, Kähler differentials `Ω[S⁄R]`, complex manifolds basics.
- Missing: metrised line bundles on `Spec O_K` and arithmetic degree, abelian varieties, Néron models, semistable reduction, integration of top forms on complex tori, regular projective model curves of function fields.

## Tau Ceti code
- `TauCeti.AlgebraicGeometry.AbelianVariety` (basic API, `AlgebraicGeometry/AbelianVariety/`). Arakelov-style heights of points and subspaces: `TauCeti.arakelovMulHeight`, `relativeSubspaceArakelovHeight` (`NumberTheory/Height/Arakelov/`), which are Euclidean heights and not degrees of hermitian line bundles.
- Missing: hermitian line bundles and `deĝ`, Néron models (no `NeronModel` anywhere), the Hodge bundle `e^*Ω^g`, the Faltings metric, `h_Fal`.

## Prerequisite chain
1. Rings of integers, embeddings, projective modules: Mathlib.
2. Abelian varieties: Tau Ceti (basic). Jacobians: target JacobianChallenge Layer D (merged, partial; representability blocked on SchemeAndStackFoundations §4.14).
3. Hermitian line bundles over `Spec O_K`, `deĝ`, product formula, finite extension: target PR #1000 §§1.1–1.6.
4. Néron models, identity components, Hodge bundle `e^*Ω^g`: target PR #852 Layer 1 (§1.11) and PR #1000 §2.4.
5. Grothendieck semistable reduction theorem and base change of semistable identity components: target PR #852 §3.10 (semistable after finite separable extension) and §3.3 (identity models and finite base change).
6. Faltings metric (integration on `A_σ(ℂ)`): target PR #1000 §2.1. Needs complex-analytic `A(ℂ)` and integration of `(g,g)`-forms (ComplexTori / ComplexKahlerGeometry, merged).
7. `h_Fal(A)` over number fields: target PR #1000 §3.4.
8. Function-field `h_Fal(C)` via regular projective model curve and `deg_{B'/k}`: target PR #1833 §13.1 (curves only).

## Library-scale gap
Small: #1833 §13.1 should be stated for an arbitrary abelian variety over a one-variable function field, not only Jacobians of curves. The definition is identical (Néron model over `B'`, Hodge line degree), and #852's semistable reduction already works over Dedekind bases. Otherwise none beyond the PRs (Faltings, *Endlichkeitssätze*; Cornell–Silverman, *Arithmetic Geometry*, Ch. II and X).
