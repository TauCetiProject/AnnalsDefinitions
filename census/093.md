## Prerequisite chain
1. Simple polygon P ⊂ ℝ², sides, vertices, inward normals: Mathlib `Polygon`, Tau Ceti `IsJordanCurve`, `TauCeti.SimplePolygon`; `PolygonalDomain`: PR #2231 §9.1; polygonal table carrier: PR #2255 §7.1.
2. Phase space `T_1(P)=(P×S¹)/∼` with reflections: PR #2231 §9.2, PR #2255 §7.2.
3. Billiard trajectory, collision times, finiteness of collisions in finite time (93.3a), null singular set Σ (93.3b): PR #2231 §9.2, PR #2255 §§7.3, 8.1.
4. Billiard flow `F^t` on `X_P`, Borel measurability, Liouville measure and its invariance: PR #2231 §9.3, PR #2255 §§8.2–8.3.
5. Weak mixing of a measure-preserving ℝ-flow (no measurable eigenfunctions / ergodicity of F×F): PR #2231 §1.0, §3.2; PR #2255 Layer 12.
6. For the rational case (Thm 1.3 of the paper): unfolding to translation surfaces, straight-line flows: PR #2255 Layers 9–11.

## Library-scale gap
PR #2231 supplies piece (a), the ergodic theory of flows (mixing and weak mixing for measure-preserving actions and real flows, spectral characterisations, suspension flows and cross-sections; Cornfeld–Fomin–Sinai, *Ergodic Theory*, Ch. 1, 6, 11; Walters ch. 1-2), and the polygonal billiard flow itself. PR #2255 (MathematicalBilliards) supplies the same flow and weak-mixing notion, together with (b), the unfolding of rational polygons: reflection groups, translation surfaces, directional flows and the Katok–Zemlyakov conjugacy (Tabachnikov, *Geometry and Billiards*; Masur–Tabachnikov, "Rational billiards and flat structures", Handbook of Dynamical Systems 1A). What remains for the definition is review and merging of PR #2231 or PR #2255, which overlap on the billiard flow. The paper's further theorems need strata of translation surfaces, the `SL₂(ℝ)` action and Masur–Veech theory, which PR #2255 names outside it and no roadmap plans beyond the open TeichmüllerGeometry PR #1169.
