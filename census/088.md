# 88. Weak functorial transfer to GL_N

## Status
ROADMAP-PR. Open PR #1756 "AutomorphicLFunctionsAndLocalFactorsPartII: roadmap", §10.1 "weak functorial transfer", is CFK Definition 2.2. For split `Sp_{2n}`, `SO_{2n}`, `SO_{2n+1}`, `GSpin_{2n}`, `GSpin_{2n+1}` and the standard `r_G`, a weak transfer is automorphic `Π` on `GL_N` with matching Satake classes at almost all unramified places and the `r_G`-image infinitesimal character at every archimedean place. This is exactly the generality of the cited paper. The general notion for an arbitrary L-representation `r : ᴸG → GL_N` (88.1 in general) is only partly specified: PR #1180 §1.6 defines weak lifts along algebraic `R : GL_n → GL_N`. The L-group itself is a merged target (ReductiveGroupsPartII RG2.5), not implemented. Nothing is implemented.

- Missing: reductive groups over number fields, adelic points, automorphic representations, unramified representations and the Satake isomorphism, dual groups, L-groups, Harish-Chandra isomorphism and infinitesimal characters.

- Reductive group infrastructure: root data, pinnings, `TauCeti.Pinning`, split reductive groups, Chevalley group schemes (`Algebra/AlgebraicGroup/{Reductive,Pinning,Chevalley}`), point topology on `G(F_v)` and congruence subgroups. Local Weil group.

## Merged roadmaps

It explicitly leaves "Hecke algebras, the Satake isomorphism and the smooth representations built on them" to a later roadmap. STATUS: RG2.5 untouched ("There are no ... dual groups yet").

## Prerequisite chain
1. Lie algebras, enveloping algebras, `GL_N`: Mathlib.
2. Split reductive groups, root data, pinnings: Tau Ceti (ReductiveGroups, largely done).
3. Dual group and L-group: target ReductiveGroupsPartII RG2.5 (merged, not implemented).
4. Harish-Chandra isomorphism and infinitesimal characters (Def. #5): LieHighestWeight Layer 7 (merged, done for semisimple Lie algebras) plus PR #1037 §2.2.
5. Adelic points and automorphic representations with local components (Def. #67): PR #792 (AdelicAlgebraicGroups), PR #1037 §§3.4–3.5, PR #871 ALS.F.6.
6. Unramified representations, Satake parameters, unramified transfer `r_*(π_v)` (88.1): Satake in PR #1688 SR.4. The transfer along `r` is implicit in PR #1756 §10.1 for standard `r_G`, and in PR #1180 §1.6 for algebraic `R` on `GL_n`.
7. Archimedean matching of infinitesimal characters (88.2): target PR #1756 §0.4 (standard `r_G`).
8. Weak functorial transfer (88.3): target PR #1756 §10.1 (split classical groups, standard `r_G`); the general L-representation version is unplanned.

## Library-scale gap
Small, if generality matters: a general "transfer along an L-representation `r : ᴸG → GL_N`" (unramified transfer through Satake parameters `t_v ⋊ Frob_v`, and the `dr` image of infinitesimal characters through `𝔥^* = 𝔱̂`) would naturally sit in #1756 Layer 0 or in #1037 next to infinitesimal characters, specialising to §10.1. Reference: Borel, *Automorphic L-functions* (Corvallis), §§2–7.
