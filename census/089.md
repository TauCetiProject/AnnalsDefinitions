# 89. ℓ-adic Galois representation with values in the Mumford–Tate group

## Status
ROADMAP-PR. Open PR #933 "Roadmap: complex Shimura varieties and canonical models", §7.0i.1 "Mumford–Tate-valued ℓ-adic Galois representations and Frobenius classes", states Def. 89.2–89.4 essentially verbatim. That covers `E^𝐆`, `ρ_ℓ^𝐆`, `Conj_𝐆 = 𝐆//𝐆` with `χ_𝐆`, and `γ_ℓ(v)`, with Checks matching Remarks 2–3. §7.0i covers Deligne's absolute Hodge theorem (89.1). Open PR #2131 "ReductiveGroupsPartIII" builds `Conj(G)` and the Kisin–Zhou reductive-group half on top of it. The Mumford–Tate group (Def. #13) is PR #1038 §1.2 / #933 §P.3a. Nothing is merged or implemented.

## Prerequisite chain
1. Galois groups, continuous homomorphisms: Mathlib.
2. Rational Hodge structures, abelian varieties, Hopf-algebra group schemes: Tau Ceti.
3. Mumford–Tate group (Def. #13): target PR #1038 §1.2 and PR #933 §P.3a.
4. `H¹_B(A(ℂ),ℚ)` with Hodge structure, `H¹_ét(A_Ē,ℚ_ℓ)` (or `V_ℓA^∨`), comparison isomorphism: targets in PR #849 / AbelianSchemesAndArithmeticModuli (Layer A5) and ComplexComparisonPartII (PR #848 §C6.6), as cited by #933.
5. Deligne: Hodge cycles on abelian varieties are absolutely Hodge (89.1): target PR #933 §7.0i.
6. Conjugation quotient `Conj_G`, `χ_G`: target PR #856 ("Reductive quotients over fields and DVRs") and PR #2131 Layer 0.
7. Néron–Ogg–Shafarevich, Frobenius at good-reduction places: PR #852 §5.1, PR #856 §§2.1–2.2.
8. `ρ_ℓ^𝐆`, `γ_ℓ(v)`: target PR #933 §7.0i.1.

## Library-scale gap
