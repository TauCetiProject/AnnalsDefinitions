# 47. Sobolev class W^{1,p}_loc(M, N) of continuous maps between manifolds

## Status
UNPLANNED (as an owned target). Draft PR 2134 "QuasiregularMaps: roadmap" writes a precise supplier contract for exactly this class (gaps `sobolev-maps-class`, `-weak-differential`, `-norm`, `-jacobian`, `-chain-rules`, `-euclidean`). It assigns ownership to a roadmap "SobolevMapsBetweenManifolds", which exists neither merged nor as an open PR. The Euclidean prerequisites are already in Tau Ceti code.

## Mathlib
- Has: charts/atlases, `ContMDiff`, `mfderiv`, `IsRiemannianManifold`, orientations, `LinearMap.det`, `Measure.map`, Lebesgue measure; Mathlib has no weak derivatives on domains.
- Missing: weak derivatives, W^{1,p}_loc, anything for maps between manifolds.

## Tau Ceti code
- Euclidean Sobolev: `TauCeti.HasWeakFDerivOn`, `TauCeti.W1p` (`Analysis/Sobolev/W1p/`), with `ChainRule.lean` (Lipschitz C¹ outer function), `ChangeOfVariables.lean`, `Gluing.lean`, `Density.lean`; local W^{k,p} on planar sets `MemWkpLoc` (`Analysis/Sobolev/Local/Basic.lean`, ℂ only).
- Manifold scalar Sobolev on closed manifolds: `TauCeti.Manifold.SobolevH1` (`Geometry/Manifold/Riemannian/Sobolev/{H1,Chart}.lean`); bundle W^{k,p} (Psido Layer 5, implemented per STATUS).
- Riemannian volume, orientations: present.
- Missing: the chartwise class of continuous maps M → N, the weak differential `Df`, `‖Df‖`, J_f.

## Merged roadmaps
- None specifies maps between manifolds. Related: Yamabe Y1 (scalar W^{k,p} finite-chart adapter on closed manifolds), PseudodifferentialOperators §5.2 (bundle W^{k,p}), PDE Lane A (Euclidean W^{1,p}, chain rule, change of variables).

## Prerequisite chain
1. Charts, `mfderiv`, orientation, Riemannian metric/volume: Mathlib + Tau Ceti.
2. Euclidean W^{1,p}, weak derivative, chain rule with C¹ outer function, change of variables under diffeomorphisms: Tau Ceti (global W^{1,p}(Ω)); the W^{1,p}_loc variant on general Euclidean opens, chain rule for continuous u with C¹ (not globally Lipschitz) F: small extensions, unplanned.
3. Null sets on manifolds via charts: unplanned (contracted in PR 2134 as SobolevMapsBetweenManifolds §3.1).
4. Class W^{1,p}_loc(M,N), chart independence (Prop 47.2), weak differential Df: specified only as a supplier contract in PR 2134; owner unwritten.
5. ‖Df‖ and J_f (47.3(c),(d)), Hadamard bound: same.
6. Consumers: quasiregular maps #41, quasiregularly elliptic manifolds #42 (PR 2134).

## Library-scale gap
Write the SobolevMapsBetweenManifolds roadmap that PR 2134 already contracts against: Euclidean W^{1,p}_loc with locality and chain rules, chart null sets, the continuous Sobolev class of maps between manifolds with its weak differential, pullback of forms by Sobolev maps (needed by Heikkilä–Pankka for de Rham algebras), and the equivalence with the Nash-embedding definition (Remark 2). References: Ziemer, *Weakly Differentiable Functions*, Ch. 2; Iwaniec–Martin, *Geometric Function Theory and Non-linear Analysis*, Ch. 4–6; Rickman, *Quasiregular Mappings*, Ch. I. It sits between PDE Lane A and PR 2134.
