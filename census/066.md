## Status
PREREQS-ROADMAPPED. Strict convexity of ∂M (positive-definite second fundamental form of the boundary with outward normal) is not itself a target; the second fundamental form of an embedded hypersurface is RiemannianGeometry R5a, and GeometricCurrents G7 already uses a mean-convexity hypothesis on ∂K for barriers. Positive-definiteness is a one-line predicate on top of #49.

## Mathlib
Has manifolds with boundary (`ModelWithCorners`, `modelWithCornersEuclideanHalfSpace`, `ModelWithCorners.boundary`/`interior` API), Riemannian metrics, Levi-Civita. No boundary second fundamental form or boundary normal coordinates.

## Tau Ceti code
Euclidean `TauCeti.secondFundamentalForm`/`shapeOperator` only. Tau Ceti Riemannian code is largely boundaryless; GeometricTopology Layer 1.1 smooth collars not started: only topological collars exist (`IsCollar`/`IsCollared`, Brown's collaring theorem, `boundaryCollar` in `Geometry/Manifold/Boundary/Collar/`), with no smooth collar structure, existence or uniqueness up to isotopy. No II_{∂M}, no strict convexity, no boundary normal coordinates.

## Merged roadmaps
- RiemannianGeometry R5a (B, S of immersions; sources may have boundary in R5a.1) and R5a.2 (principal curvatures): applying them to ∂M → M (or ∂M → an extension M̃) gives 66.1. Not implemented. R5a sign convention B(X,Y) = normal part of ∇_X Y; def #66 uses the outward-normal Weingarten convention, so the sphere has II = +g there and S_ν = −Id in R5a.2; a sign adapter is needed.
- GeometricCurrents G7: compact domain K with "⟨tr B_{∂K}, ν⟩ < 0" (strict mean convexity) as a barrier hypothesis. Mean-convex only, inside a boundaryless ambient.
- GeometricTopology Layer 1.1 smooth collars (needed for boundary normal coordinates 66.2b). Not started; only the topological collar infrastructure is in code.
- No roadmap targets strictly convex boundary, boundary defining function Hessian formula, or boundary normal coordinates (grep).

## Prerequisite chain
manifold with boundary, Riemannian metric [Mathlib] -> extension to an open manifold / collar [GT Layer 1.1, not started; topological collars only in Tau Ceti] -> second fundamental form of ∂M (#49 applied to ∂M) [RiemannianGeometry R5a, not implemented] -> II via boundary defining function Hess ρ / |dρ| and via ∂_r h_r (66.2) [unplanned] -> (strictly) convex / concave boundary (66.3) [unplanned, trivial] -> geodesics tangent to ∂M leave/stay (66.2c) [unplanned].

## Library-scale gap
A "Riemannian manifolds with boundary" layer: boundary normal (Fermi) coordinates, distance to the boundary, convexity of the boundary and its consequences for geodesics, the boundary distance function and lens data (Katchalov-Kurylev-Lassas, *Inverse Boundary Spectral Problems*; Paternain-Salo-Uhlmann, *Geometric Inverse Problems*, Ch. 3). It would extend RiemannianGeometry R5a/R6 (focal geometry and squared distance) and feed an X-ray transform / boundary rigidity roadmap (Stefanov-Uhlmann-Vasy).
