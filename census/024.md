# 24. Moduli stack of stable maps M̄_{g,n}(X, β)

## Status
ROADMAP-PR. Open PR #1998 (GromovWittenTheory) Layer 3 defines `MbarMap g n X β` and proves it a proper DM stack; merged roadmaps specify the object-level stable maps (StableReduction Layers 10–11, partly implemented) and stacks (SchemeAndStackFoundations §§1.18–1.23, §4.15) but explicitly stop before the stable-map moduli stack.

Used by #27 (virtual class); uses #16 only through #27.

## Mathlib
- No stacks in the algebraic-geometry sense, no nodal curves, no stable maps. Category-theoretic descent exists: `CategoryTheory/Sites/Descent/IsStack.lean` (`Pseudofunctor.IsStack`), `IsPrestack`, `DescentData`.

## Open roadmap PRs
- #1998 "roadmap: develop algebraic Gromov-Witten theory and quantum cohomology": Layer 2 `Mpre g n` (smooth Artin stack of prestable curves, dimension `3g−3+n`) and `Mbar g n`; Layer 3 `MbarMap g n X β` (full substack of families with stable geometric fibres of numerical class `β`; boundedness via Hilbert schemes; separated DM of finite type; properness via StableReduction's valuative interface; universal curve, `ev_i`, `st`, gluing). Uses numerical classes `β ∈ N_1(X)` (Layer 0), a variant of 24.2's `Pic(X) → ℤ`; for the quintic these agree.
- #990 "Add Gromov–Witten theory roadmap" and #987 AnalyticStableMaps: symplectic/analytic stable maps (pseudoholomorphic), not the algebraic stack; would not serve 24.4 directly.

## Prerequisite chain
1. Nodal/prestable pointed curves: Tau Ceti (`AtWorstNodalOfRelativeDimensionOne`, pointed prestable families; StableReduction Layers 1, 3 partial).
2. Prestable maps, contracted components, degree: Tau Ceti (StableReduction Layers 10–11, partial).
3. `IsStableMap`, openness of stability: StableReduction Layer 10 (merged, not implemented).
4. Stacks in groupoids, algebraic/DM stacks, properness: SchemeAndStackFoundations §§1.18–1.20 (merged, not implemented).
5. Hilbert/Quot/Hom schemes for boundedness: SchemeAndStackFoundations §4.14 (merged, not implemented).
6. `M̄_{g,n}(X,β)` as CFG, algebraic DM, proper: PR #1998 Layers 2–3.
7. (24.5 boundedness/properness theorem): PR #1998 Layer 3.

## Library-scale gap
Covered by PR #1998 once merged. If the definition alone were wanted earlier, the CFG of 24.4 is a small extension of StableReduction Layer 10 plus SchemeAndStackFoundations §1.18; algebraicity and properness are the real work.
