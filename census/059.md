## Status
PARTIAL-CODE. Tau Ceti has the smooth mapping class group `TauCeti.MappingClassGroup I M` = π₀ Diff(M, ∂M) of a compact manifold, possibly with boundary, with `Mod⁺` for an orientation (`Geometry/Diffeomorphism/MappingClassGroup.lean`): the object of merged GeometricTopology 1.7.2 for compact surfaces with boundary fixed pointwise, a close variant that agrees with Definition 59 only after capping or marking, which no code provides. Merged [MordellLawrenceVenkatesh](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/MordellLawrenceVenkatesh/README.md) specifies the definition: §5.1 (surfaces `Σ ∖ P`, `Σ` compact connected oriented with boundary, `P` a finite set of interior punctures; 59.1) and §5.9 (`Mod(S)`, isotopy classes of orientation-preserving homeomorphisms of `S` fixing `∂S`, punctures may be permuted; 59.2, 59.5 for `∂S = ∅`). Merged [TeichmullerGeometry](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/TeichmullerGeometry/README.md) §0.0h adds `MappingClassGroupFull M` for every space (homeomorphisms modulo those isotopic to the identity), which on `Σ_{g,n}` is `Mod^±_{g,n}`. Not targets of a merged roadmap: Proposition 59.4 (extension over the punctures; open PR #2430 §2.2), the permutation homomorphism `Mod_{g,n} → Sym(P)` and its kernel `PMod_{g,n}` (PR #2430 §2.3, PR #2266 §0.2; MordellLawrenceVenkatesh §5.9 names the pure subgroup only in a Check).

## Mathlib
No mapping class groups. Has `Homeomorph` groups, `ContinuousMap.Homotopy`, compact-open topology, `Homeomorph` topological group structure on locally compact spaces, `Diffeomorph`.

## Tau Ceti code
- `TauCeti.MappingClassGroup I M` (`Geometry/Diffeomorphism/MappingClassGroup.lean`): for a compact Hausdorff smooth manifold `M`, possibly with boundary, the quotient of the relative diffeomorphism group `Diff(M, ∂M)` (`TauCeti.RelativeDiff`, weak Whitney topology) by the path component of the identity, with `mk`, `mk_surjective`, `ker_mk`, `mk_eq_mk_iff` (same class iff joined by a path), `lift`, `mk_final_eq_one` (a diffeotopy ends in the trivial class) and the subgroup `orientationPreserving o` (`Mod⁺(M)`). Diffeomorphisms, boundary fixed pointwise; no homeomorphism version, no punctures or marked points, no Dehn twists, no computation for surfaces.
- Diffeomorphism groups and isotopies exist: the relative diffeomorphism group `TauCeti.RelativeDiff` (`Geometry/Diffeomorphism/FixingSubgroup/Basic.lean`) with the topology of `Geometry/Diffeomorphism/Topology.lean`, `TauCeti.Diffeotopy` (`Geometry/Diffeomorphism/Diffeotopy/Basic.lean`), `TauCeti.SmoothIsotopic` (`Geometry/Manifold/SmoothIsotopy/Basic.lean`), `SmoothAmbientIsotopic`, `ContinuousAmbientIsotopic` (`Geometry/Manifold/SmoothEmbedding/...`), `TauCeti.Isotopic` (named by TeichmullerGeometry §0.0h). Surface groups as presented groups `TauCeti.SurfaceGroup.Orientable g m` (`GroupTheory/SurfaceGroup/Basic.lean`). Group-theoretic `dehnTwist` for HNN extensions/pushouts only (`GroupTheory/HNNExtension/DehnTwist.lean`, `GroupTheory/PushoutI/DehnTwist.lean`).
- Open Tau Ceti PR https://git.taucetiproject.org/TauCetiProject/TauCeti/pulls/2232 (TeichmullerGeometry §0.0h: the topological mapping class group of isotopy classes of homeomorphisms).
- Open Tau Ceti PR https://github.com/TauCetiProject/TauCeti/pull/45253 (MordellLawrenceVenkatesh §5.1: `TauCeti.PuncturedSurface X` with its oriented carrier `X ∖ P`, LowDimTopology/Surface/{Basic,Disk}.lean).
