## Status
ROADMAP-PR. The mapping class group of a punctured surface (orientation-preserving homeomorphisms, punctures may be permuted, modulo isotopy) is a target of PR #1231 §5.9; merged GeometricTopology 1.7.2 only covers compact surfaces with boundary (boundary fixed pointwise, diffeomorphisms).

## Mathlib
No mapping class groups. Has `Homeomorph` groups, `ContinuousMap.Homotopy`, compact-open topology, `Homeomorph` topological group structure on locally compact spaces, `Diffeomorph`.

## Tau Ceti code
No mapping class group. Isotopy notions exist: `TauCeti.SmoothIsotopic` (`Geometry/Manifold/SmoothIsotopy/Basic.lean`), `SmoothAmbientIsotopic`, `ContinuousAmbientIsotopic` (`Geometry/Manifold/SmoothEmbedding/...`), `TauCeti.Isotopic` (named in PR #1169). Group-theoretic `dehnTwist` for HNN extensions/pushouts only (`GroupTheory/HNNExtension/DehnTwist.lean`).
