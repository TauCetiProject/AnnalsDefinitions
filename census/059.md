## Status
ROADMAP-PR. The mapping class group of a punctured surface (orientation-preserving homeomorphisms, punctures may be permuted, modulo isotopy) is a target of PR #1231 §5.9; PR #2266 §0.2 builds the pure subgroup `PMod(g, b, p)` on it and PR #2263 §2.1 the braid group as the mapping class group of the marked disc. Merged GeometricTopology 1.7.2 only covers compact surfaces with boundary (boundary fixed pointwise, diffeomorphisms).

## Mathlib
No mapping class groups. Has `Homeomorph` groups, `ContinuousMap.Homotopy`, compact-open topology, `Homeomorph` topological group structure on locally compact spaces, `Diffeomorph`.

## Tau Ceti code
No mapping class group. Diffeomorphism groups and isotopies exist: the relative diffeomorphism group `TauCeti.RelativeDiff` (`Geometry/Diffeomorphism/FixingSubgroup/Basic.lean`) with the topology of `Geometry/Diffeomorphism/Topology.lean`, `TauCeti.Diffeotopy` (`Geometry/Diffeomorphism/Diffeotopy/Basic.lean`), `TauCeti.SmoothIsotopic` (`Geometry/Manifold/SmoothIsotopy/Basic.lean`), `SmoothAmbientIsotopic`, `ContinuousAmbientIsotopic` (`Geometry/Manifold/SmoothEmbedding/...`), `TauCeti.Isotopic` (named in PR #1169). Surface groups as presented groups `TauCeti.SurfaceGroup.Orientable g m` (`GroupTheory/SurfaceGroup/Basic.lean`). Group-theoretic `dehnTwist` for HNN extensions/pushouts only (`GroupTheory/HNNExtension/DehnTwist.lean`, `GroupTheory/PushoutI/DehnTwist.lean`).

## Prerequisite chain
homeomorphism group, compact-open topology [Mathlib] -> closed oriented surface Σ_g, orientation of homeomorphisms [PR #1231 §5.1-5.6; GT 1.7 for smooth compact surfaces] -> isotopy as normal subgroup Homeo₀ (59.2-59.3) [PR #1169 §0.0h `isotopicToIdSubgroup`; PR #1231 §5.9] -> extension to Σ_g preserving P (59.4) [PR #1231] -> Mod_{g,n} (59.5) [PR #1231 §5.9] -> PMod_{g,n} [PR #2266 §0.2] -> Birman exact sequence [PR #1231 §5.20; pure version PR #2266 §0.3].
