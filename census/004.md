# 4. Parabolic subgroups of a real semisimple Lie group (minimal and standard parabolics)

## Status
PARTIAL-CODE. Tau Ceti has algebraic parabolic `k`-subgroups (`TauCeti.HopfIdeal.IsParabolic`) and dynamic cocharacter parabolics `P_G(λ)` with Levi decomposition, i.e. the algebraic-group variant of Remark (1)–(2); the Lie-group objects the Zimmer-program papers use (minimal `P = MAN`, standard `Q_{Π'} ⊇ P`, Langlands decomposition) are not in code. Minimal parabolics with Langlands decomposition are a target in open PR #1037 §2.3a; standard parabolics `Q_{Π'}` are not a target anywhere. Depends on #1 (𝔞, restricted roots).

## Mathlib
- Has: `LieGroup`, `RootPairing`/`RootSystem` with bases (`LinearAlgebra/RootSystem/*`), `Subgroup.normalizer`.
- Missing: Cartan involutions, restricted roots, Iwasawa data, parabolic subgroups of Lie groups or algebraic groups.

## Tau Ceti code
- Algebraic: `TauCeti.HopfIdeal.IsParabolic` / `IsParabolicOverAlgClosed` (smooth, contains a Borel after base change), `of_le`, conjugation invariance, `exists_conjugate_le` (`Algebra/AlgebraicGroup/Parabolic/Basic.lean`); dynamic parabolics `TauCeti.Cocharacter.parabolic`, `parabolicDefiningHopfIdeal`, `BialgHom.parabolicLeviFppfQuotientIso`, `parabolicCoordinateAlgEquiv` (`Algebra/AlgebraicGroup/Dynamic/*`); `GL_n` weight parabolics classification (`GeneralLinear/Weight/Parabolic/Classification.lean`). Tits systems and Bruhat cells `TauCeti.TitsSystem.existsUnique_mem_bruhatCell` (`GroupTheory/TitsSystem/Bruhat/Uniqueness.lean`).
- Lie group: only `GL n` Iwasawa (`TauCeti.iwasawaDiffeomorph`); no `MAN`, `Q_{Π'}` or Langlands decomposition.

## Merged roadmaps
- RepresentationTheory/LieGroups Layer 9: `IwasawaData` (𝔞, `positiveRestrictedRoots`, `Nplus`, chamber), `iwasawaDecomposition`, KAK; supplies everything Setup 4.1 needs except `M = Z_K(𝔞)` and `P = MAN`. STATUS partial (`GL n` only). No merged roadmap targets real parabolics, `M = Z_K(𝔞)`, `P = MAN`, Langlands decomposition or real rank.
- ReductiveGroups Layer 7 (parabolic `k`-subgroups, cocharacter description `P_G(λ)`, Levi, relative root system) and Layer 7b (algebraic parabolics and Levi intersections, comparison with standard parabolics in split groups). STATUS: Layer 7 partial ("general parabolic Levi theory" remaining), 7b untouched.
- RepresentationTheory/LieGroups Layer 8 (complex flag manifolds, Bruhat; minimal parabolic `P_α` for complex groups); untouched. Weak link: it is complex flag geometry and contains nothing on parabolics of real groups.

## Open roadmap PRs
- #1037 "Automorphic forms on reductive groups" §2.3a "Minimal parabolic subgroups and the Langlands decomposition": defines `M = Z_K(𝔞)`, `P = MAN`, proves `M×A×N → P` diffeo, `P = N_G(𝔫)`, `G = KP`, conjugacy of minimal parabolics, and `P = G ∩ 𝐏(ℝ)` for a minimal ℝ-parabolic (Def 4.2 and Remark (2) for minimal ones). §2.4 Langlands classification uses standard parabolics/Levis but does not specify `Q_{Π'}` or Theorem 4.4.
- #871 ArithmeticLocallySymmetricSpaces: rational parabolics and Levi quotients of `Res_{F/ℚ}G` (Borel–Serre); not real Lie-group parabolics.
- #1756, #1688: consume ReductiveGroups Layer 7 rational parabolics.

## Prerequisite chain
1. Root system bases, simple roots: Mathlib.
2. Cartan involution, 𝔞, restricted roots `Σ`, positive system: LieGroups Layers 7, 9 (merged, not implemented); see #1.
3. `M = Z_K(𝔞)`, `A`, `N`, `P = MAN`, Langlands decomposition, conjugacy: PR #1037 §2.3a.
4. `𝔮_{Π'}`, `Q_{Π'} = N_G(𝔮_{Π'})`, bijection `Π' ↦ Q_{Π'}` onto subgroups containing `P`, `Q_{Π'} = ⋃ PwP`, Levi `L_{Π'}` and `M_{Π'}A_{Π'}N_{Π'}`: unplanned. Bruhat part could reuse `TauCeti.TitsSystem` (standard parabolic subgroups of a Tits system are a Bourbaki-level exercise).
5. Algebraic ℝ-parabolics and their dynamical description: Tau Ceti code (`IsParabolic`, `Cocharacter.parabolic`); comparison `Q = G ∩ 𝐐(ℝ)`: PR #1037 §2.3a for minimal only.
6. Complex-group `P_s` for `s ∈ i𝔨` (Higgs paper): dynamic `Cocharacter.parabolic` covers rational `s`; real `s` unplanned.
