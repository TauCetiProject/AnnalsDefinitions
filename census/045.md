# 45. Schrödinger operator −Δ + V on L²(ℝ^d)

## Status
ROADMAP-PR. Open PR 1027 (UO-E06) specifies −Δ with domain H² on L²(ℝ³) and the self-adjointness of −Δ + V for real V ∈ L² + L^∞, but only in d = 3. The paper needs d ≥ 2 with bounded smooth V. For bounded V that case needs no more than the bounded Kato–Rellich theorem, which Tau Ceti already has, plus the free Laplacian on L²(ℝ^d), which is still missing.

## Mathlib
- Has: Fourier transform on L² (`Analysis/Fourier/LpSpace`), tempered-distribution Fourier multipliers, Bessel potential spaces `TemperedDistribution.MemSobolev` / `BesselPotentialSpace` (`H^{s,p}(E,F)`, so H²(ℝ^d) = H^{2,2}), Laplacian `InnerProductSpace.instLaplacian`, `LinearPMap` and `IsSelfAdjoint`.
- Missing: −Δ as a self-adjoint `LinearPMap` on L²(ℝ^d), Schrödinger operators.

## Tau Ceti code
- Bounded and relatively bounded Kato–Rellich: `IsSelfAdjoint.add_of_isRelativelyBounded` (`Analysis/InnerProductSpace/LinearPMap/KatoRellich.lean`), `Analysis/Normed/Operator/LinearPMap/RelativeBound.lean`, perturbation constructors `LinearAlgebra/LinearPMap/Perturbation.lean` (Prop 45.3).
- Bounded multiplication operator: `multiplicationOperator` (`MeasureTheory/Function/Lp/Multiplication.lean`).
- Heat semigroup on Lᵖ(ℝⁿ): `TauCeti.heatSemigroup`, generator on C²_c `generator_heatSemigroup` (`Analysis/PDE/HeatKernel/`); full generator domain = H² not found.
- Schrödinger with V ≥ 0 on closed manifolds, form level only (`Geometry/Manifold/Riemannian/Sobolev/Schrodinger.lean`); not ℝ^d.
- Missing: −Δ on L²(ℝ^d) with domain H² as a self-adjoint partial operator; −Δ + V.

## Prerequisite chain
1. Fourier–Plancherel on L², H^{2,2}(ℝ^d): Mathlib.
2. Self-adjoint maximal multiplication operator by |ξ|²: target PR 1027 UO-A07.
3. Free Laplacian H₀ on L²(ℝ^d), domain H², self-adjoint, σ = [0, ∞), C_c^∞ core: target PR 1027 UO-E06 for d = 3 only; general d unplanned but a trivial generalization (and implicit in PDE §6.3 at p = 2).
4. Bounded Kato–Rellich: Tau Ceti.
5. H = −Δ + V for V ∈ L^∞ real, any d: PR 1027 UO-E06 (d = 3); general d is a one-line instance of 3 + 4.
6. Spectral measures and σ_ac (needed to state the paper's theorem): definition #35, target PR 1027 UO-C03.
7. Quasi-periodic potentials: elementary trigonometric polynomials, no gap.

## Library-scale gap
Small: generalize UO-E06's free-Laplacian construction from ℝ³ to ℝ^d (only the L² potential part is dimension-restricted). The paper's content (Bethe–Sommerfeld, multiscale perturbation theory for quasi-periodic operators) is far beyond, but stating it needs only 45 and 35. Reference: Reed–Simon II, §X.2 and IX.7; Teschl, *Mathematical Methods in Quantum Mechanics*, Ch. 7 and 10.
