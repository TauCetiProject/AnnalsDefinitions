## Status
PARTIAL-CODE. For countable relational languages the definition is in Tau Ceti: `TauCeti.RelationalConfiguration L ℕ` is Mod_L(ω) with the product topology, Polish and standard Borel instances (98.1, 98.2(a)), clopen atomic conditions and Borel `modelsOf φ` (98.2(c)), the jointly continuous relabelling action of the Polish group `Equiv.Perm ℕ` (`instContinuousSMulPerm`) with `isoSetoid = orbitRel` and analytic isomorphism relation (98.3), `IsomorphismInvariant` (98.4), and López–Escobar (`exists_modelsOf_eq_iff`, 98.5). Missing: languages with function symbols, which Definition 98.1 includes and the cited paper (Paolini–Shelah, in the language of groups) uses; the graph coding of function symbols exists only syntactically. The merged roadmap [CountableStructureSpacesPartII](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/CountableStructureSpacesPartII/README.md) §1.3 specifies the functional coding space for languages with function symbols (Polish, continuous `Equiv.Perm ℕ` action, orbits the isomorphism classes, Borel model classes of first-order theories) and its continuous equivariant embedding onto a Gδ subset of the graph-language coding space; it is not implemented.
