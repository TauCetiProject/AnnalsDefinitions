## Status
ROADMAP-PR
Open PR #1208 (WeilConjectures §7.12) defines the Enriques condition in a characteristic-free form: numerically trivial `ω` with `χ(O)=1`. It proves equivalence with Schröer's `b₂ = 10` convention (Definition 19.2). PR #1488 Layer 0 builds on it. PR #1286 covers characteristic `≠ 2`. No merged roadmap targets it.

## Mathlib
- Present: smooth and proper morphisms, `Scheme`, the `fppfTopology`, pro-étale `Scheme.EllAdicCohomology` (definition only; no finiteness).
- Missing: coherent cohomology of schemes, the canonical sheaf `Ω²` as an invertible sheaf, numerical equivalence, étale `ℓ`-adic Betti numbers with finiteness.

## Tau Ceti code
- Coherent cohomology of schemes and Euler characteristics (`AlgebraicGeometry/Cohomology/`, `EulerCharacteristic.lean`).
- `LineBundleClass` and `LineBundleClass.eulerDegreeHom` (degree on curves via `χ`, `WeilDivisor/Scheme/PicZero.lean`).
- Kähler differentials sheaf (`AlgebraicGeometry/Modules/Differentials/`).
- Intersection numbers (`AlgebraicGeometry/IntersectionNumber/`).
- The surface intersection pairing and numerical equivalence of line-bundle classes (SSF §§5.9–5.10 definitions): `Chow.intersectionNumber` (`χ(𝒪) − χ(L⁻¹) − χ(M⁻¹) + χ(L⁻¹ ⊗ M⁻¹)`), `Chow.NumericallyEquivalent` and the quotient `Chow.Num` (`AlgebraicGeometry/Chow/SurfaceIntersection.lean`). Bilinearity and the group structure on `Num` are not proved.
- Exterior powers of sheaves of modules (`AlgebraicGeometry/Modules/ExteriorPower/`).
- Curve canonical bundle (`LineBundle/SerreDuality.lean`).
- Missing: `ω_Y = ⋀²Ω` as an invertible sheaf on smooth surfaces, `b_i` via étale cohomology (ECF unimplemented), and any Enriques declaration.

## Prerequisite chain
1. Smooth proper schemes over `k`. In Mathlib.
2. Coherent cohomology, `χ`, `h⁰`. In Tau Ceti.
3. Canonical sheaf `ω_Y` of a smooth surface. Unplanned explicitly; Tau Ceti has `Ω¹` (needs `⋀²`).
4. Numerical triviality on a surface. In Tau Ceti: `Chow.NumericallyEquivalent` to the trivial class (`Chow/SurfaceIntersection.lean`, SSF §§5.9–5.10).
5. `b₂` via `ℓ`-adic étale cohomology. Target in merged ECF §F.4.5 (unimplemented); PR #1208's `χ(O)=1` variant avoids it.
6. Enriques surface. Target in PR #1208 §7.12, used by PR #1488 Layer 0.

## Library-scale gap
Planned across PRs #1208, #1286 and #1488. References: Cossec–Dolgachev, *Enriques Surfaces I*; Bombieri–Mumford II–III. The `b₂ = 10` form needs merged ECF; the `χ(O)=1` form does not, which makes it the cheaper formal definition.
