# 5. Infinitesimal character (and Casimir eigenvalue) of a representation of a real reductive group

## Status
PARTIAL-CODE. The algebraic core is in Tau Ceti for semisimple Lie algebras over an algebraically closed field of characteristic 0: modules with prescribed central character (`TauCeti.centralCharacterModules`), the Harish-Chandra isomorphism (`TauCeti.harishChandraIso`), Verma central characters with `χ_λ = χ_μ ↔ μ ∈ W·λ`, and the Casimir. Missing: the reductive (e.g. `gl_n`) Harish-Chandra isomorphism and the group-level definition via smooth vectors; `HasInfinitesimalCharacter` for real reductive groups is a target of open PR #1037 §2.2.

## Mathlib
- Has: `UniversalEnvelopingAlgebra`, `Subalgebra.center`, `killingForm`, `LieAlgebra.IsKilling`, Cartan subalgebras and `rootSystem`, Weyl group of a root pairing.
- Missing: Harish-Chandra isomorphism, central characters, Casimir, smooth vectors of Lie group representations.

## Tau Ceti code
- `TauCeti.centralCharacterModules (χ : Subalgebra.center R A →ₐ[R] R)` (`Algebra/Category/ModuleCat/CentralCharacter/Basic.lean`): Def 5.2(1) verbatim for `A = U(𝔤)`.
- `TauCeti.harishChandraIso`, `harishChandraLinearIso` (`Algebra/Lie/HighestWeight/CentralCharacter/Isomorphism.lean`), `vermaCentralCharacter`, `vermaCentralCharacter_eq_iff` (dot-orbit criterion), `range_hcProjection` (`.../Surjective.lean`), `exists_isDominantIntegral_eq_vermaCentralCharacter`: Theorem 5.1 for Killing (semisimple) `L`, split Cartan, char 0.
- `TauCeti.casimirElement`, `casimirElement_mem_center` (`Algebra/Lie/UniversalEnveloping/Casimir.lean`), `vermaCentralCharacter_casimirElement`, `casimirScalar` (`Algebra/Lie/HighestWeight/Casimir.lean`): Def 5.4 for the Killing form.
- `gl_n`: trace-form Casimir `glCasimir` (`Algebra/Lie/GeneralLinear/Casimir.lean`), `glIrreducible`, reductive structure and `centralWeight` (`Algebra/Lie/Reductive/Basic.lean`, `Algebra/Lie/Weights/Central.lean`). `U(𝔤)` as left-invariant differential operators on smooth functions on a Lie group, `TauCeti.envelopingAction` (`Geometry/Lie/EnvelopingAlgebra/Basic.lean`).
- Not present: reductive `Z(U(𝔤)) ≅ S(𝔥)^W` (gl_n), `(𝔤,K)`-modules, smooth vectors / differentiated action of a Lie group representation.

## Prerequisite chain
1. `U(𝔤)`, centre, Killing form, root systems: Mathlib.
2. Central-character module predicate, HC isomorphism (semisimple, alg. closed), Casimir: Tau Ceti.
3. Descent from `𝔤₀ ⊗ ℂ` with `ℂ` (alg. closed, char 0) is fine; reductive HC iso `Z(U(𝔷 ⊕ 𝔤')) ≅ S(𝔷) ⊗ Z(U(𝔤'))`: gap recorded in PR #1037 (would extend LieHighestWeight Layer 9), unplanned as a merged target.
4. Lie algebra of a Lie group: LieGroups Layers 0–5 (merged, partial; Layer 5 has `U(𝔤)` acting on smooth functions only). Smooth vectors of continuous reps on locally convex spaces and the `U(𝔤)` action on them: PR #1037 §2.7.
5. `(𝔤,K)`-modules, admissibility, `HasInfinitesimalCharacter`: PR #1037 §§2.1–2.2.
6. Langlands-parameter compatibility (Remark 2): PR #1037 §2.5.

## Library-scale gap
After PR #1037: only the reductive HC isomorphism (Knapp, *Lie Groups Beyond an Introduction*, Ch. V §§5–7; Humphreys, *Introduction to Lie Algebras*, §23) as an extension of LieHighestWeight Layer 9.
