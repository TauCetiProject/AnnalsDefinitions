# 34. Neumann eigenvalues and eigenfunctions of the Laplacian on a bounded domain

## Status
ROADMAP-PR. Open PR 1614 "PDE Mixed Boundary Conditions" (Lane G, item 32) specifies the Neumann (Γ = ∅) spectrum of −Δ on a bounded connected Lipschitz domain via the form ∫∇u·∇v on H¹(Ω); merged PDE has only the Dirichlet spectrum, which is implemented.

## Mathlib
- Has: Laplacian `InnerProductSpace.instLaplacian`, `LinearPMap.IsSelfAdjoint`, compact operators and the spectral theorem for compact self-adjoint operators, whole-space Bessel potential spaces `BesselPotentialSpace` (`H^{s,p}(E,F)`).
- Missing: H¹(Ω) on a domain, Neumann form, Neumann eigenvalues.

## Tau Ceti code
- Prerequisites present: `TauCeti.W1p` (W^{1,p}(Ω)), Rellich on bounded Lipschitz domains `TauCeti.W1p.isCompactOperator_valueL_of_isLipschitzDomainWith`, Poincaré–Wirtinger `W1p.exists_eLpNorm_value_sub_setAverage_le_of_isCompactOperator`, constants from zero gradient `W1p.exists_value_ae_eq_const_of_gradient_eq_zero`, trace `W1p.frontierTrace`, Courant–Fischer for compact operators (`Analysis/InnerProductSpace/CourantFischer.lean`).
- Dirichlet analogue implemented: `TauCeti.PDE.dirichletSolutionOperator`, `IsDirichletEigenvalue`, `firstDirichletEigenvalue`, `exists_hilbertBasis_nat_isDirichletEigenvalue_monotone` (`Analysis/PDE/Spectrum/`), and the Dirichlet realization as an unbounded operator `TauCeti.PDE.dirichletOperator` on `L²(Ω)` with compact resolvent `hasCompactResolvent_dirichletOperator`, spectrum `spectrum_dirichletOperator` and self-adjointness for symmetric forms (`Analysis/PDE/Spectrum/Operator.lean`), built on the abstract inverse/resolvent API (`Analysis/InnerProductSpace/LinearPMap/Inverse.lean`, `Topology/Algebra/Module/LinearPMap/Resolvent/Inverse.lean`) and the Green operator of a self-adjoint operator with compact resolvent (`Analysis/InnerProductSpace/LinearPMap/Green.lean`).
- Interior regularity (PDE §5.1): interior `H²`/`Hᵏ` estimates and the C^∞ bootstrap, `UniformlyEllipticOn.exists_value_eq_value_restrictL_of_contDiffOn` (`Analysis/PDE/Regularity/HigherOrder.lean`), `UniformlyEllipticOn.exists_contDiffOn_ae_eq` (`Analysis/PDE/Regularity/Smooth.lean`); Lipschitz-coefficient `H²` via `exists_lowerOrder_eq_restrictL_of_locallyLipschitzOn`.
- Missing: Neumann solution operator / eigenvalues (no "neumann" in `Analysis/PDE`, `Analysis/Sobolev`).

## Merged roadmaps
- PDE §4.4 (D19) "The Dirichlet spectrum": Dirichlet only; implemented. PDE §1.6 (Lipschitz domains, trace, Rellich): the needed compactness H¹(Ω) ↪ L²(Ω); implemented in large part.
- `TauCetiRoadmap/VariationalMethods/` ([README](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/VariationalMethods/README.md)): compact form pairs (§3.1), successive minima and Courant–Fischer on the form domain `CompactFormPair.eigenvalue_eq_rayleighMinMax` (§§4.1–4.4, the min–max formula of Thm 34.2 and 34.4(c)), the represented operator and the differential-energy adapter `D₀†D₀` (§§5.1–5.3). Abstract; it does not mention Neumann conditions. Not implemented (no `CompactFormPair` in Tau Ceti).
- No merged roadmap specifies Neumann eigenvalues.

## Open roadmap PRs
- PR 1614 "PDE Mixed Boundary Conditions", Lane G item 32 "Mixed and Neumann spectra": resolvent (−Δ_Γ+1)⁻¹ via Lax–Milgram on H¹_Γ(Ω), compact by Lipschitz Rellich, eigenvalues λ_k with orthonormal eigenbasis; for Γ = ∅ first eigenvalue 0 with eigenspace the constants. Item 31 gives the pure Neumann problem. Restricts to connected Ω (34 allows disconnected; trivial difference).
- Not specified anywhere: Prop 34.3 regularity (real analyticity inside, C^∞ up to smooth boundary, polygon corner behaviour, classical ⇔ weak equivalence), which the two papers use to pass between classical and weak formulations.

## Prerequisite chain
1. H¹(Ω), Lipschitz domains, Rellich, Poincaré–Wirtinger: Tau Ceti (PDE §1.1, §1.5, §1.6 targets, implemented).
2. Compact self-adjoint spectral theorem / Courant–Fischer: Mathlib + Tau Ceti.
3. Neumann form, resolvent, eigenvalue sequence μ_k, eigenspace of 0 = locally constant: target PR 1614 item 32 (not implemented).
4. Min–max on the form domain: target of merged VariationalMethods §4.4, not implemented.
5. Interior regularity (Δu = μu classically, analytic): PDE §5.1 (E20) interior H^k estimates and C^∞ bootstrap (merged; the interior part is implemented, only the global boundary versions of Layer 5 remain); analyticity unplanned.
6. Boundary regularity on C^∞ domains and on polygons, and the classical–weak equivalence (Prop 34.3(ii),(iii)): unplanned (PDE Layer 5 lists "global boundary estimates" as remaining but for Dirichlet; Neumann boundary regularity and corner analysis not specified).

## Library-scale gap
The definition itself is covered by PR 1614. What the papers additionally need is Neumann boundary regularity: global H² / C^∞ regularity up to a smooth boundary for the Neumann problem and corner regularity on polygons (Grisvard, *Elliptic Problems in Nonsmooth Domains*, Ch. 4–5; Evans §6.3 for the smooth case). This would naturally extend PDE Lane E / PR 1614's Lane G.
