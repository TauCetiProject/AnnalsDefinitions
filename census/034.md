# 34. Neumann eigenvalues and eigenfunctions of the Laplacian on a bounded domain

## Status
ROADMAP-MERGED. Merged [PDE](https://github.com/TauCetiProject/TauCetiRoadmap/blob/main/TauCetiRoadmap/PDE/README.md) specifies the definition in full as §4.6 "Mixed and Neumann spectra (D21)" of its Layer 4 (merged PR #1614), with §4.5 (mixed and Neumann problems) and §1.8 (boundary parts, `H¹_Γ(Ω)`): for `Γ = ∅` on a bounded Lipschitz domain, weak Neumann eigenvalues against all of `H¹(Ω)` (34.1), the eigenbasis and nondecreasing enumeration with finite multiplicities, the min–max formula, the Neumann kernel as the locally constant functions with multiplicity of `0` the number of components (Theorem 34.2), the second eigenvalue as the mean-zero Rayleigh minimum with its minimisers (34.4(c)), and the self-adjoint realization with compact resolvent (Remark (1)). The Dirichlet spectrum of §4.4 is implemented; §1.8 is partly in code (admissible boundary parts, `W^{1,p}_Γ(Ω)` with its empty case `H¹(Ω)`, Poincaré–Friedrichs); §4.5 is not started, and of §4.6 only the Neumann kernel is in code (locally constant functions, of dimension the number of components on a bounded Lipschitz domain). Tau Ceti's `IsCoercive.formOperator` applied to `W^{1,2}(Ω)` with the Rellich value map gives the Neumann operator; this application is not in code. Proposition 34.3 (regularity, the classical problem), which both papers use, is left by the PDE roadmap's scope (README l.48) to a later PDE part and is not specified anywhere.

## Prerequisite chain
1. H¹(Ω), Lipschitz domains, Rellich, Poincaré–Wirtinger: Tau Ceti (PDE §1.1, §1.5, §1.6 targets, implemented).
2. Compact self-adjoint spectral theorem / Courant–Fischer: Mathlib + Tau Ceti.
3. Neumann form, resolvent, eigenvalue sequence μ_k, eigenspace of 0 = locally constant functions, min–max and the second eigenvalue: target of merged PDE §4.6 (on §§1.8, 4.5), partly in code; §1.8's `H¹_Γ(Ω)` with its empty case and Poincaré–Friedrichs, §4.6's finiteness of components and its Neumann kernel (the locally constant functions, of dimension the number of components) are in code (`w1pVanishingOnSubmodule`, `Set.IsLipschitzDomain.finite_connectedComponents`, `PDE.forall_energyFormH1_one_zero_zero_eq_zero_iff_exists_isLocallyConstant`, `W1p.finrank_ker_gradientL_of_isLipschitzDomain`); §4.5 has the open Tau Ceti PRs cited above; the abstract eigenbasis and operator are Tau Ceti `IsCoercive.exists_hilbertBasis_forall_apply_eq_smul_inner` and `IsCoercive.formOperator` on the Hilbert space `W1p mu Ω 2`.
4. Min–max on the form domain: also target of merged VariationalMethods §4.4 in abstract form, not implemented; its §§3.1–3.2 compact form pairs and constrained minima are partly in code (`TauCeti.CompactFormPair`, `exists_isMinOn_energy_unitConstraint`), and its §3.4 form kernel and kernel-orthogonal Poincaré connector are in code (`CompactFormPair.formKernel`, `kernelOrthogonal`).
5. Interior regularity (Δu = μu classically, analytic): PDE §5.1 (E20) interior H^k estimates and C^∞ bootstrap (merged; the interior part is implemented, only the global boundary versions of Layer 5 remain); analyticity unplanned.
6. Boundary regularity on C^∞ domains and on polygons, and the classical–weak equivalence (Prop 34.3(ii),(iii)): unplanned (PDE Layer 5 lists "global boundary estimates" as remaining but for Dirichlet; Neumann boundary regularity and corner analysis not specified).

## Library-scale gap
None for the definition: merged PDE §4.6 specifies it, so what remains is implementation of the rest of §1.8 and of §§4.5 and 4.6 along the Dirichlet route in code. What the papers additionally need is Neumann boundary regularity: global H² / C^∞ regularity up to a smooth boundary for the Neumann problem and corner regularity on polygons (Grisvard, *Elliptic Problems in Nonsmooth Domains*, Ch. 2, 4–5; Evans §6.3 for the smooth case). The PDE roadmap assigns this to a later PDE part, after Layer 5's global (Dirichlet) estimates.
