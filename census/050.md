## Status
PARTIAL-CODE. Tau Ceti has smooth nondegenerate metrics of arbitrary signature with locally constant signature and their Levi-Civita connection, so a smooth Lorentzian metric is expressible; time orientation, spacetime, low-regularity (C^k, C^{k,α}, C^0) metrics and causal-character API are absent and not roadmapped.

## Mathlib
No Lorentzian or pseudo-Riemannian metric. Has `LinearMap.BilinForm.Nondegenerate`, `QuadraticForm` signature/Sylvester (`QuadraticForm.equivalent_signType_weighted_sum_squared`), `Bundle.RiemannianMetric` (positive definite only).

## Tau Ceti code
- `TauCeti.Manifold.ContMDiffNondegenerateMetric` (`Geometry/Manifold/VectorBundle/NondegenerateMetric/Basic.lean`): smooth symmetric nondegenerate bilinear-form section, no signature fixed.
- `ContMDiffNondegenerateMetric.signature`, `isLocallyConstant_signature`, `signature_eq` (`.../NondegenerateMetric/Signature.lean`): Lorentzian = signature (n,1).
- Levi-Civita for nondegenerate metrics: `Geometry/Manifold/VectorBundle/CovariantDerivative/LeviCivita/Nondegenerate/{Basic,Existence,Christoffel,Family,Variation}.lean`; along-curve API `CovariantDerivative/AlongCurve/NondegenerateMetric.lean`.
- Missing: Lorentzian scalar product predicate/timelike cones (50.2), time orientation, future/past directed, C^k/Hölder metrics, metrics on manifolds with boundary/corners, C^0 extension.

## Library-scale gap
A "Lorentzian geometry and causality" roadmap: Lorentzian linear algebra, time orientations, causal curves and futures J^±/I^±, achronal sets and Cauchy hypersurfaces, global hyperbolicity, Lorentzian geodesics and Raychaudhuri, plus low-regularity metrics (O'Neill, *Semi-Riemannian Geometry*, Ch. 5, 14; Beem-Ehrlich-Easley, *Global Lorentzian Geometry*; Minguzzi's Living Review on causality; Hawking-Ellis). It would sit beside RiemannianGeometry and consume HopfRinow L1's nondegenerate Levi-Civita; LVF6 and PR #1772 would be downstream. Wave equations on Lorentzian manifolds (Bär-Ginoux-Pfäffle) would be the natural PDE follow-up.
