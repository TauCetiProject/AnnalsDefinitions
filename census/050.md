## Status
PARTIAL-CODE. Tau Ceti has smooth nondegenerate metrics of arbitrary signature with locally constant signature and their Levi-Civita connection, so a smooth Lorentzian metric is expressible; time orientation, spacetime, low-regularity (C^k, C^{k,α}, C^0) metrics and causal-character API are absent from code. Open PR #2232 (LorentzianGeometry) specifies the whole definition: Lorentzian scalar products and causal characters (§6.1, 50.1), time cones (§6.2, 50.2), the regularity extension of `ContMDiffNondegenerateMetric` to `C^k` on manifolds with boundary or corners, Hölder classes and the `LorentzianMetric I M k` subtype (§2.2, §2.3, §7.1, 50.3), time orientations, spacetimes and causal curves including locally Lipschitz causal and timelike ones (§§8.1–8.2, 50.4), and `C^l`-extensions and inextendibility, independent of the boundaryless model space so that it is inextendibility among all extensions of the same dimension (§2.7, 50.5), with Levi-Civita and curvature for `C^k` metrics (§§2.4–2.5) and the double null and acoustical examples (§2.2 Checks, §7.3) of the remarks. No merged roadmap specifies it.

## Mathlib
No Lorentzian or pseudo-Riemannian metric. Has `LinearMap.BilinForm.Nondegenerate`, `QuadraticForm` signature/Sylvester (`QuadraticForm.equivalent_signType_weighted_sum_squared`), `Bundle.RiemannianMetric` (positive definite only).

## Tau Ceti code
- `TauCeti.Manifold.ContMDiffNondegenerateMetric` (`Geometry/Manifold/VectorBundle/NondegenerateMetric/Basic.lean`): smooth symmetric nondegenerate bilinear-form section, no signature fixed.
- `ContMDiffNondegenerateMetric.signature`, `isLocallyConstant_signature`, `signature_eq` (`.../NondegenerateMetric/Signature.lean`): Lorentzian = signature (n,1).
- Levi-Civita for nondegenerate metrics: `Geometry/Manifold/VectorBundle/CovariantDerivative/LeviCivita/Nondegenerate/{Basic,Existence,Christoffel,Family,Variation}.lean`; along-curve API `CovariantDerivative/AlongCurve/NondegenerateMetric.lean`.
- Missing: Lorentzian scalar product predicate/timelike cones (50.2), time orientation, future/past directed, C^k/Hölder metrics, metrics on manifolds with boundary/corners, C^0 extension.

## Prerequisite chain
nondegenerate bilinear forms, Sylvester [Mathlib] -> smooth nondegenerate metric + signature [Tau Ceti, HopfRinow L1 done] -> Lorentzian scalar product theory: timelike cones, reverse Cauchy-Schwarz (50.1, 50.2) [PR #2232 §§6.1–6.2] -> Lorentzian metric of class C^k/C^{k,α}/C^0 on manifolds with boundary/corners [PR #2232 §§2.2–2.3, §7.1; smooth case in code] -> time orientation, future/past directed, causal curves [PR #2232 §§8.1–8.2] -> spacetime, C^k extension and inextendibility (50.5) [PR #2232 §8.1, §2.7].

## Library-scale gap
PR #2232 is the "Lorentzian geometry and causality" roadmap (O'Neill, *Semi-Riemannian Geometry*, Ch. 5, 14; Beem-Ehrlich-Easley, *Global Lorentzian Geometry*; Minguzzi's Living Review on causality; Hawking-Ellis; Chruściel-Grant): Layers 1–5 generalize HopfRinow L1's nondegenerate metric, Levi-Civita, curvature, geodesic, immersion and Jacobi APIs to finite regularity and every signature; Layers 6–13 cover Lorentzian linear algebra, time orientations, causal curves and futures J^±/I^±, null geometry, the causal ladder, achronal sets and Cauchy surfaces, global hyperbolicity and splitting, `C^0`-inextendibility, Raychaudhuri and the Hawking and Penrose theorems. What remains for the definition is review and merging of PR #2232. Wave equations on Lorentzian manifolds (Bär-Ginoux-Pfäffle) and the Einstein Cauchy problem are outside it and are the natural PDE follow-up; open PR #2442 (CompressibleEulerEquations) is the follow-up for the acoustical metric of compressible fluids.
