## Prerequisite chain
1. Compact metric space, continuous f, `M(f)`, ergodic measures: Mathlib.
2. Topological entropy: Mathlib `Dynamics.coverEntropy`.
3. KS entropy (97.1): PR #2231 §4.0 (`measureEntropy`, `measureEntropy_eq_iSup_finite`), also stated in PRs #851 §4.2 and #1335 §2.6.
4. `h_μ ≤ h_top`, entropy affinity/ergodic decomposition (97.2(b)): PR #2231 §6.1 (Goodwyn), §4.10 (entropy integration), §6.2 (Jacobs).
5. Variational principle `h_top = sup h_μ` (97.2(a), reverse inequality, Misiurewicz's proof): PR #2231 §§7.1-7.2.
6. MME (97.3) and its basic properties (97.4(a)-(b): convexity, extreme points, existence under upper semicontinuity): PR #2231 §§8.1-8.2, with upper semicontinuity for expansive maps in §6.2.
7. Example without m.m.e. (97.4(c)): a homeomorphism in PR #2231 §8.2; Misiurewicz's `C^r` diffeomorphisms, Newhouse upper semicontinuity for C^∞ maps, Buzzi-Crovisier-Sarig finiteness for surface diffeos: unplanned, named outside PR #2231 (needs Pesin theory / Yomdin).

## Library-scale gap
PR #2231 is the entropy theory of classical ergodic theory (Walters, *An Introduction to Ergodic Theory* ch. 4, 7, 8; Downarowicz, *Entropy in Dynamical Systems*): KS entropy (with PR #851's names), SMB and the ergodic decomposition of entropy, the Kolmogorov-Sinai generator theorem, Abramov and Abramov-Rokhlin formulas, the full variational principle, upper semicontinuity for expansive maps and existence of MMEs, uniqueness under specification, entropy of shifts and toral automorphisms; it specifies the generic parts of PR #1335 §§2.6-2.7 and PR #851 §4.2 itself and feeds #96 (pressure). What remains for the definition is review and merging of PR #2231. The paper's theorems further need smooth ergodic theory (Ruelle inequality, Pesin theory, Yomdin/Newhouse; Barreira-Pesin, *Nonuniform Hyperbolicity*), which no roadmap plans; PR #2231 names smooth ergodic theory outside it.

Depends on #96 only through the remark that MME = equilibrium states of potential 0 (the definition is independent).
