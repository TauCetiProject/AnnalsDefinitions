## Prerequisite chain
1. Compact metric space, continuous f, `M(f)`, ergodic measures: Mathlib.
2. Topological entropy: Mathlib `Dynamics.coverEntropy`.
3. KS entropy (97.1): target in PR #851 §4.2 (`measureEntropy`), consumed by PR #1335 §2.6.
4. `h_μ ≤ h_top`, entropy affinity/ergodic decomposition (97.2(b)): PR #1335 §2.7.
5. Variational principle `h_top = sup h_μ` (97.2(a), reverse inequality, Misiurewicz's proof): PR #2231 §§7.1-7.2.
6. MME (97.3) and its basic properties (97.4(a)-(b): convexity, extreme points, existence under upper semicontinuity): PR #2231 §§8.1-8.2, with upper semicontinuity for expansive maps in §6.2.
7. Newhouse upper semicontinuity for C^∞ maps, Buzzi-Crovisier-Sarig finiteness for surface diffeos: unplanned (needs Pesin theory / Yomdin).

## Library-scale gap
PR #2231 is the entropy theory of classical ergodic theory (Walters, *An Introduction to Ergodic Theory* ch. 4, 7, 8; Downarowicz, *Entropy in Dynamical Systems*): KS entropy (taking PR #851's API), the Kolmogorov-Sinai generator theorem, Abramov and Abramov-Rokhlin formulas, the full variational principle, upper semicontinuity for expansive maps and existence of MMEs, entropy of shifts and toral automorphisms; it consumes the generic parts of PR #1335 §§2.6-2.7 and PR #851 §4.2 and feeds #96 (pressure). What remains for the definition is review and merging of PRs #2231, #851 and #1335. The paper's theorems further need smooth ergodic theory (Ruelle inequality, Pesin theory, Yomdin/Newhouse; Barreira-Pesin, *Nonuniform Hyperbolicity*), which no roadmap plans.

Depends on #96 only through the remark that MME = equilibrium states of potential 0 (the definition is independent).
